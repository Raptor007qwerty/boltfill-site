Boltfill

Type it once. Use it everywhere.

A Chrome extension for the text you type over and over. Save it once, give it a shortcut, and expand it in a text box on any site you have allowed.

/email → john@example.com

Boltfill is on the Chrome Web Store now, and the version you can install today is the free, local one described above. It needs no account, sends nothing anywhere, and has no time limit.

Accounts, cloud sync and Pro are not live yet. Everything below about signing in, folders, tags, history and the two Pro prices arrives with the 0.4 update, which is finished and waiting on Chrome Web Store review. Until it is approved there is nothing to sign in to and nothing to buy, so please do not expect those features in the copy you have installed today.

How it works

  1. Save a shortcut

    Open Boltfill and pair a shortcut such as /email with the text it stands for.

  2. Allow the websites you want

    Boltfill asks for no website access when you install it. You grant it explicitly, and you can take it back at any time.

  3. Type the shortcut

    In a text box on an allowed site, typing /email becomes your saved text.

What it does

Ordinary fields and rich editors

Works in form fields, textareas and rich text editors. Line breaks, emoji and non-English text survive intact.

Instant or deliberate

Expands the moment a shortcut is complete, or waits for a space if you prefer. A shortcut that starts a longer one waits automatically.

Search and organise

Search matches both the shortcut and the text inside it. Deleting offers an undo rather than a confirmation dialog.

Per-site exclusions

Name a site and Boltfill will never run there, subdomains included.

Backup you control

Export everything to a plain JSON file on your computer, and import it back. Nothing is uploaded.

Light and dark

Follows your system theme, is keyboard navigable, and does no background work when idle.

Pricing

Boltfill Free is a complete text expander, not a trial. It has no time limit, no nag screens and no advertising, and it does not require an account. Pro exists because syncing snippets between computers costs us money to run.

Both plans below describe the 0.4 update, which is awaiting review. Pro is not on sale yet, and the cloud sync listed under Free is part of the same update. The copy on the Chrome Web Store today is local-only and entirely free.

Free — $0

  • Works with no account at all
  • Optional cloud sync: 2 devices, 10 MB
  • Import, export, site exclusions, sensitive-field protection
  • Everything on this page above

Pro — $19.99 a year

or $2.49 a month. Annual is $9.89 cheaper over a year — $19.99 against $29.88.

  • 10 synced devices instead of 2
  • 100 MB of cloud backup instead of 10 MB
  • Folders and tags
  • 30-day history, so an edit or a deletion can be undone

Cancelling never deletes anything. If you stop paying, your snippets, folders and tags all stay exactly where they are and Boltfill keeps working. If you are over the free limits, it stops accepting new cloud data and new devices rather than removing what you already have. Your local snippets are untouched either way.

Payment is handled by Lemon Squeezy, who are the merchant of record. Boltfill never sees your card — it has no code that could accept one.

Private by construction

  • No account, and no network, unless you ask for one. Signed out, Boltfill makes no network requests whatsoever — your snippets sit in Chrome's local storage and go nowhere. That is the default and it is a complete product.
  • Sync is a choice, not a condition. If you sign in, your snippets are also stored on Boltfill's server so your other computers can read them. They are encrypted in transit and at rest, but this is not end-to-end encryption — we could read them, and we would rather say so than imply otherwise.
  • No analytics, no telemetry, no trackers. Not in either mode. Boltfill does not record which sites you visit, what you type, or how often you use it.
  • Expansion never needs the internet. Shortcuts expand from your own device, so Boltfill works on a plane whether you have an account or not.
  • No website access at install. A fresh install can read and change nothing until you grant access.
  • It refuses sensitive fields. Boltfill never expands inside password, card number, CVV, one-time-code or similar fields.

The full detail is in the privacy policy.

Boltfill is not a password manager

Please do not store passwords, card numbers, CVV codes, one-time codes, private keys, recovery phrases or banking credentials in Boltfill. Its storage is not encrypted beyond the protection Chrome gives your profile, and it is not designed to be a secrets vault. Use a real password manager for those.
